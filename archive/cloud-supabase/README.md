# archive/cloud-supabase — parked, not in use

**desktop-only, personal, free** app. Kept because it was tested (Postgres 17 + pgvector 0.8.7, tenant-isolation tests
passed) and maps 1:1 to the local SQLite schema, so it is the starting point if ImageVault ever adds cloud sync or
multiple users. Nothing here is built, deployed or paid for.
